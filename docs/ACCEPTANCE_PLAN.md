# Keylane V0.1 实施计划与验收清单

状态：**用户已确认，V0.1 开发版已实现，完整验收进行中**。本文件以 [产品文档](PRODUCT.md)、[技术文档](TECHNICAL.md)、[设计规范](../DESIGN.md) 和 [交互原型](../prototype/index.html) 为依据。原型只模拟界面，不作为下列功能通过的证据；已执行检查见 [验证记录](VERIFICATION.md)。

## 1. 背景与边界

Keylane 是个人固定内网站点的 Chrome 登录入口。用户在 Popup 或 Side Panel 找到常用站点，点击后由扩展打开或定位登录页，核对站点、生成本次凭据，再填充或提交。管理页维护规则和手动导入导出。首版支持固定密码、秒／毫秒时间戳的 Base64，以及站点专属 JS；密码与脚本允许本地明文保存。首版不做云同步、服务端、团队共享、主密码、通用认证成功识别或浏览器商店发布。

**验收口径：**“已填充”表示字段已设置；“已提交”表示提交动作已发出，均不等于服务器认证成功。所有自动化与浏览器验收只用虚构站点和凭据。常用排序、150ms 骨架延迟、5s 配置读取超时、15s 页面等待上限及导入疑似重复规则是**已确认的实施约定**；原型不作为其实现证据。

## 2. 核心流程与具体架构

```text
Popup / Side Panel / 管理页
  → 登录命令（站点 ID、当前页或新页）
  → Service Worker：选取目标站点 → 检查权限 → 打开/定位 Tab → 核对最终 URL
  → 无凭据探针：确认目标文档、表单或页面函数已就绪
  → 凭据来源：固定值 / 临近执行时生成时间戳 / USER_SCRIPT 凭据脚本
  → 登录动作：打包的 ISOLATED 表单脚本 / MAIN 页面脚本
  → 已填充、已提交或明确失败；不自动重复提交
```

| 组件 | 职责与数据边界 |
| --- | --- |
| 三个扩展页面 | 共享站点列表、配置表单和状态文案；只发送站点 ID 与命令，不把全部凭据广播给页面。Popup 常用列表按“常用”分组优先、其余按配置顺序补足，默认最多 5 条。 |
| 领域层 | 校验版本化 `Site`、规范化 URL、按协议／主机／端口／路径段匹配，生成时间戳密码，验证导入文件和冲突；这些逻辑可脱离 Chrome API 测试。 |
| `chrome.storage.local` | 一个版本化配置文档，保存站点、明文静态密码、脚本与脚本启用状态；限制内容脚本访问。权限实时向 Chrome 查询，不把原型的 `permission` 布尔值当作持久事实。 |
| `chrome.storage.session` | 仅存任务 ID、站点 ID、Tab ID、阶段与截止时间，不存密码；供 Service Worker 休眠重启后识别任务。扩展重载／浏览器重启后任务中断，不能自动重放提交。 |
| Service Worker 与注入器 | 从配置文档提取本次目标站点，仅把其规则交给执行器；权限和最终 URL 双重检查；先无凭据探测，再锁定文档执行；标准表单用打包函数，自定义 JS 用 `chrome.userScripts.execute()`。 |

表单 selector 必须是合法 CSS 且命中唯一目标；“仅填充”不要求提交按钮 selector。等待目标元素的上限为 15s，超时后结束任务。导入冲突按相同 `site.id` 判定；规范化登录地址与路径约束相同但 ID 不同的条目标记为“疑似重复”，不自动覆盖。

目标 Chrome 为 **138+**。官方文档说明 `userScripts.execute()` 自 Chrome 135 起提供脚本结果与 `documentIds` 目标，138 起使用扩展级“Allow User Scripts”开关。`MAIN`／`USER_SCRIPT` 两种 world 已在本机 Chrome 154 的扩展测试中跑通；Chrome 138 实机仍待检查。见 [User Scripts API](https://developer.chrome.com/docs/extensions/reference/api/userScripts)、[Scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)。[Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage) 与 [Service Worker 生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle) 是任务恢复边界的依据。

## 3. 界面状态契约

| 场景 | 进入时 | 完成、空数据或失败时 |
| --- | --- | --- |
| Popup／Side Panel 首次读配置 | 超过 150ms 仍未读完才显示列表形骨架屏；`aria-busy`，站点动作不可点击，不绘制虚构站点或密码。 | 成功后立即替换为列表；零站点显示“添加第一个站点”；读取失败或超过 5s 显示“读取失败／重试”，不能伪装成空列表；迟到的读取结果不能覆盖错误／重试后的新状态。 |
| 管理页首次读配置 | 同样超过 150ms 才在保留的导航框架内显示列表行和右侧检查器骨架。 | 成功后进入列表／空态；失败显示重试，未保存的编辑不得被空数据覆盖。 |
| 当前页匹配 | 当前页条显示“正在检查”，不先显示“已匹配”。 | URL 匹配后显示站点；已授权才可“在当前页登录”，未授权显示“授权”；不匹配、不可访问或查询失败显示明确不可用状态。 |
| 保存／删除配置 | 提交时禁用重复操作并显示“保存中／删除中”，保留当前草稿。 | 成功后更新列表；写入失败保留草稿并可重试，不假报成功。 |
| 一次登录 | 当前实现一次只运行一个登录任务；执行期间锁定登录动作，依次显示“检查／等待授权 → 打开／等待页面 → 核对地址 → 填充／执行”。 | “已填充”“已提交”或带阶段的失败；超时、页面关闭可重试。执行中断且结果未知时提示先检查目标页，再由用户手动重试，绝不自动再次提交。 |
| 导入／导出 | 文件读取、校验、生成期间显示进度文字并禁用确认动作；导出前始终提示含明文密码和脚本。 | 导入先预览冲突和脚本再确认；取消或失败不改本地配置；导出失败可重试。 |

骨架屏只用于**尚不知道数据内容**的初次读取；已知为空、搜索无结果、未匹配、权限拒绝和登录进行中使用各自的文字状态。骨架不闪烁、不承载可聚焦假按钮；遵循系统“减少动态效果”偏好。

## 4. 可验证验收清单

每项须记录测试输入、实际可观察结果和截图／测试报告；源码存在或构建通过不算浏览器验收。

### 配置与入口

- [ ] **A01 站点配置**：用虚构 `http` IP:端口和 `https` 域名各建一站点；新增、编辑、删除（确认／取消）后重开扩展，列表与版本化存储一致；非法 URL、非法路径前缀、缺失必填字段不能保存；模拟写入失败时保留草稿且不假报成功。
- [ ] **A02 常用入口**：配置超过 5 个站点且含“常用”分组；Popup／Side Panel 按第 2 节规则展示前 5 条，名称、域名、凭据方式和“进入／授权”可扫读；搜索能找到其余站点，无结果显示搜索空态。
- [ ] **A03 初始与异常加载**：模拟配置读取耗时 800ms，可见不可操作的骨架屏且完成后消失；快速读取不闪骨架；模拟读取失败／5s 超时显示重试，零站点显示新增入口；键盘焦点和屏幕阅读器可辨认状态。
- [ ] **A04 权限**：用户点击“授权”或首次登录时仅请求目标站点权限；拒绝后仍可保存配置，但不注入、不向页面发送凭据，列表显示“需授权”；撤销权限后再次执行也须重新授权。浏览器权限范围和界面提示一致。

### 登录纵切面

- [ ] **A05 地址边界**：对协议、主机、端口、路径段各设一个不匹配样例（例如 `/login` 不匹配 `/login-helper`），并在页面就绪前模拟跨 origin 重定向；所有样例均停止且测试页未收到凭据。
- [ ] **A06 标准表单**：本地原生表单与监听 `input`／`change` 的表单分别收到正确虚构值；“填充并提交”恰好一次，“仅填充”零次；结果分别显示“已提交”和“已填充”。
- [ ] **A07 当前页与新页**：匹配的当前 Tab 可直接执行，不匹配页不可执行；从站点列表打开新 Tab 后等待目标页面就绪再生成凭据。`chrome://`、页面关闭和页面超时均给出可重试错误。
- [ ] **A08 元素异常**：选择器非法、无匹配、多重匹配、目标在 2s 出现或超过 15s 仍缺失，各得到确定结果；“仅填充”允许没有提交 selector；失败不提交，不把密码放入提示或日志。
- [ ] **A09 动态密码**：冻结时间分别验证秒／毫秒十进制字符串的 Base64 结果；目标就绪后才生成，失败或跳转后不提前泄露到页面。
- [ ] **A10 自定义 JS**：凭据脚本仅返回本次 `{username,password}`；页面脚本在可信测试页只收到该站点本次凭据，调用 `window.login` 并返回 `{submitted:true}`。脚本禁用、Chrome 开关关闭、语法／运行错误、返回值无效均明确失败，不回退到其他执行方式。
- [ ] **A11 任务中断**：连续双击只创建一次任务；Service Worker 休眠重启、扩展重载或 Tab 关闭后无无限加载、无第二次提交；无法确定是否已提交时显示“结果未确认，请先检查目标页”，只允许用户手动重试。

### 迁移与交付

- [ ] **A12 导出**：用户确认明文提示后导出 UTF-8 `schemaVersion: 1` JSON；含站点／明文密码／脚本，不含权限、任务、使用记录；文件名不含账号或站点名称。
- [ ] **A13 导入**：坏 JSON、未知版本、非法 URL／selector、超限脚本被拒绝且原配置不变；预览分别标出同 ID 冲突与同登录地址疑似重复。同 ID 由用户选择保留或覆盖；不同 ID 的疑似重复由用户选择跳过或作为新站点导入，不能自动覆盖。确认后单次写入；实际导入的条目其脚本一律停用，权限只从当前 Chrome 授权状态重新查询，不随文件恢复。
- [ ] **A14 跨电脑**：在独立 Chrome 配置 A 导出、B 导入后，虚构站点字段相同；B 未授权前不能注入，逐站审阅并启用脚本后才可运行。
- [ ] **A15 安全与界面**：静态密码默认遮挡；控制台、错误提示、任务状态、测试报告不出现虚构密码的明文或完整导出内容；Popup、Side Panel、管理页在键盘操作、窄宽度与减少动态效果设置下无动作遮挡或永久骨架。
