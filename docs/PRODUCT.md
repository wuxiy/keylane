# Keylane 产品文档

状态：**V0.1 开发版已实现，完整人工验收待完成**。`extension/` 为实际扩展；`prototype/` 是使用虚构数据的界面交互演示。具体验证范围见 [验证记录](VERIFICATION.md)。

## 1. 定位与目标

Keylane 是个人使用的内网登录启动器：把少量固定站点放在浏览器扩展中，点击站点即可打开登录页，填入账号与密码并提交。站点可以使用固定密码、当前时间戳的 Base64 编码值，或自定义 JS 处理特殊登录流程。

首版的成功标准是：用户不用再次寻找输入框和手动输入；站点规则由用户明确配置，可在扩展内查看与编辑，并可导出到另一台电脑后导入。

## 2. 使用边界

- 目标用户：同一人管理自己的局域网服务、开发/运维后台等固定站点。站点需要由用户信任并主动加入。
- 目标浏览器：Chrome 桌面版 Manifest V3，最低版本见技术文档。
- 首版每站点一个账号。支持 `http` 和 `https` 的主机名、IP 地址及端口。
- 本地配置允许明文保存密码；查看配置时可主动显示密码。导出文件同样含明文密码与脚本，应由用户自己保管。
- “一键登录”表示完成打开、填充和提交动作；提交成功不等于已证明服务器认证成功。界面应区分“已提交”和“登录成功”。

## 3. 首版功能范围

| 编号 | 功能 | 可见行为 |
| --- | --- | --- |
| P1 | 站点管理 | 添加、编辑、删除站点；配置名称、登录 URL、匹配路径、分组与登录规则；在管理页查看完整配置。 |
| P2 | 快捷入口 | Popup 提供搜索和一键登录；Side Panel 提供常驻列表；扩展内管理页负责完整配置与导入导出。 |
| P3 | 标准表单登录 | 配置用户名、密码、提交按钮的 CSS selector；打开站点或对当前匹配页面填充；支持“仅填充”与“填充并提交”，默认后者。 |
| P4 | 凭据来源 | 固定账号密码；当前时间戳（毫秒或秒）转十进制字符串再 Base64；自定义 JS 返回本次登录的账号密码。 |
| P5 | 自定义登录动作 | 对需要调用页面已有 JS 的站点，用户编写站点专属脚本，以本次账号密码为输入，主动点击后执行。 |
| P6 | 本地迁移 | 导出版本化 JSON；在另一台电脑预览并导入，冲突由用户选择，不静默覆盖。 |
| P7 | 可诊断结果 | 分别报告权限拒绝、地址不匹配、找不到元素、脚本不可用、脚本报错、已填充、已提交。错误提示不含密码。 |

## 4. 关键流程

### 添加站点

1. 输入站点名称和登录 URL。扩展从 URL 得到完整 origin，用户可加登录路径约束。
2. 选择凭据来源和登录动作。普通站点填写 CSS selector；特殊站点填写 JS。
3. 保存时校验 URL、selector 和规则的基本格式。保存与授权分开；用户点击“授权”或首次尝试登录时，才申请该站点访问权限。拒绝权限时配置仍保留，登录动作显示需要授权。
4. 用户可以在管理页检查配置并对目标站点发起一次测试登录。

### 一键登录

1. 用户在 Popup、Side Panel 或管理页选择站点，也可对当前已打开的匹配页面执行。
2. 扩展打开或定位页面，确认最终地址仍符合站点完整 origin 与路径，并已获得该站点权限。
3. 页面可操作后生成本次密码、执行标准表单或自定义登录动作。动态密码必须临近填写/提交时生成。
4. 界面报告“已填充”或“已提交”；是否真正进入系统由目标系统页面表现确认。失败不自动重复提交。

### 导出与导入

1. 用户在管理页主动导出 JSON，界面明确提示文件包含明文密码和脚本。
2. 另一台电脑读取文件后，先展示站点数量、目标域名、冲突和脚本清单；无效格式拒绝导入。
3. 用户确认覆盖或保留冲突条目；导入的 JS 默认停用，需逐站检查后启用；站点权限在新电脑重新申请。

## 5. 不纳入首版

自动云同步、服务端、团队共享、多账号、主密码/加密 Vault、通用网页表单识别、验证码/OTP/Passkey、跨域 SSO 自动跳转、iframe/Shadow DOM 自动处理、移动端和浏览器商店发布。站点元素点击选择器可以作为后续易用性改进，不阻塞首版。

## 6. 首版验收

| 场景 | 独立可观察结果 |
| --- | --- |
| 固定密码站点 | 在本地测试页点击站点后，正确填入两个字段且恰好提交一次；“仅填充”模式不提交。 |
| 动态密码站点 | 冻结时钟后，毫秒与秒两种配置分别产生预期 Base64 字符串；在实际页面触发时用接近提交时刻的时间。 |
| 自定义 JS | 凭据脚本返回值进入本次登录；页面脚本可调用测试页暴露的登录函数；禁用 JS 时能给出清楚提示。 |
| 权限和地址 | 未授权、跨 origin 重定向、路径不匹配均不会填入凭据。 |
| 导入导出 | 用虚构配置从浏览器 A 导出、在浏览器 B 导入后，站点配置一致；脚本停用、权限待重新授予。 |
| 错误反馈 | 缺少 selector、脚本抛错、页面超时不会假报登录成功，也不会自动重复提交。 |

验收应使用本地测试站点和虚构账号；真实内网站点可做个人手工试用，但不能把其凭据写入仓库或测试日志。
